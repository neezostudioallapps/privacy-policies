# Privacy Policy — Neezo BioinfAI Studio

Last updated: 2026-10-21

This policy describes what data Neezo BioinfAI Studio ("the program") handles. The program is published by Neezo Studios.

## 1. Data stored on your computer
Your projects (sequencing files and results), libraries (books, papers, notes, ideas), search indexes and settings are stored on your own computer. We do not operate a server that receives or stores them.

## 2. Connections the program can make
The program connects to the internet only when you use a feature that needs it. Each connection goes through one internal gate that can be switched off completely (Settings → Privacy & Network → Offline mode) and that records the feature, the server host, the path, the outcome and the number of bytes (never the content or the query) in a log you can read (View connection log). The features are:
- **Public scientific data and references:** ENA / NCBI (SRA, GEO, PubMed search, E-utilities), Crossref, Unpaywall and PubMed Central (open copies of papers), STRING (protein networks), Open Targets (disease associations). What is sent is the identifier or the words you typed or the gene names of your analysis. If you enter an e-mail address in Settings → Research services, it is sent with Crossref, Unpaywall and NCBI requests as those services ask.
- **Downloads you ask for:** reference genomes, analysis tools and AI models from their public hosts (for example Hugging Face).
- **Update check:** the program may ask GitHub for the latest release information. In the Microsoft Store build, updates come from the Store.
- **Cloud AI providers (optional):** if you enter your own API key for a provider (for example Groq, OpenAI, Anthropic, Google, DeepSeek) and use an AI, speech or embedding feature, the text, image or audio of that request is sent to that provider. Before the first send, a window shows the exact (redacted) text and asks for your permission. The provider's own privacy policy applies. If you use a local model, nothing leaves your computer for these features.

## 3. API keys
Keys are stored encrypted for your Windows account (Windows data protection or Credential Manager) and are not written to settings files or to project backups.

## 4. What we do not do
We do not collect analytics, telemetry or usage statistics; we do not track you; we do not show advertising; we do not sell or share your data; we do not require an online account.

## 5. Health-related and research data
The program is a research and education tool. If your sequencing data come from people, you are responsible for consent, de-identification and the rules that apply to you. Do not use the program for diagnosis or clinical decisions.

## 6. Deleting data
Uninstalling the program removes the program files. Your projects and libraries are in folders you chose and in your user profile (for example `%LocalAppData%\NizoStudio`); delete them yourself if you want them gone.

## 7. Children
The program is intended for researchers, students and educators and is not directed at children.

## 8. Changes
If this policy changes, the new version will be published at the same address and included with the next release.
